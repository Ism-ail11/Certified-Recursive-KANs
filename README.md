# Calibrated signed gains for recursive KANs

The gate can redistribute directional gains, damp a feedback loop, or reverse one direction in response to the input. The model fits the gate on a frozen cubic KAN with a directly solved paired equilibrium correction. This comparison isolates changes in gating from changes in the fitted feature extractor, splines, cross-stage links, and readout.

Start with [the paper tables](paper/tables/paper_tables.pdf), [the figure captions](paper/FIGURE_CAPTIONS.md), and [the standalone 3D viewer](paper/figures/interactive_3d.html). The archive contains the experimental data, checkpoints, numeric table sources, and figure-generation scripts.

## Method

For a two-way feedback pair, let $(a_0,b_0)$ be the computed injections and let $(\phi,\psi)$ be the learned piecewise-linear splines. The fixed-point equations are

\[
a=a_0+s(x)\phi(b),\qquad b=b_0+t(x)\psi(a).
\]

A 12-unit tanh gate takes the standardized input and frozen trunk representation together. Its two outputs per pair give

\[
u = \lambda\log(3)\tanh(d(x)),\qquad
\tau = 1-\lambda+\lambda\tanh(r(x)),\qquad
s=e^u,\quad t=e^{-u}\tau.
\]

The strength $\lambda$ lies in $[0,1]$. The loop gain obeys $|st|=|\tau|\le 1$ in real arithmetic. The spline product has projection target 0.72, and inference verifies an outward upper product below one using the represented gains. The first scale is positive, so the ordered first spline knots still locate the breakpoints of the scalar composition. The solver evaluates active affine segments and enumerates breakpoints when needed. The signed second direction changes the response while preserving the fixed-point certificate.

For pair slope bounds $(A,B)$ and outward residual bounds $(r_a,r_b)$, the error bounds are

\[
|a-a^*|\le\frac{r_a+A r_b}{1-AB},\qquad
|b-b^*|\le\frac{r_b+B r_a}{1-AB}.
\]

The second stage receives the propagated first-stage error. The absolute correction weights map the hidden-state interval to an output interval. Arithmetic uses binary64 and conservative outward allowances for interpolation, sums, dot products, and rounding. The guarantees apply to the represented feedback equations and the affine correction for a given computed trunk feature vector.

At strength zero the gate returns the original fixed gains exactly. The fitting stage updates only gate parameters. After gate training and early stopping, validation compares strengths $0,0.125,0.25,0.5,0.75,1$. Selection takes the smallest strength whose validation loss exceeds the minimum grid loss by at most 0.2% of the fixed-anchor validation loss. The held-out strength curves are descriptive. The signed full-strength row uses the same gate parameters and bypasses strength selection.

## Comparisons

The standard cubic KAN, fixed-gain paired KAN, and original reciprocal-gain paired KAN were refit from their documented architectures and training settings. The frozen-anchor comparisons share the fixed model's exact parameters. Those comparisons include a learned input-independent gain, a contextual reciprocal gain with unit loop multiplier, a full-strength signed gain, and the validation-calibrated signed gain.

Five seeds are used on both larger tasks. Bike Sharing uses the same chronological holdout across initialization seeds. Letter Recognition uses five seeded group-stratified splits that keep equal descriptor vectors together within each split. All scaling uses training observations. Bike scores use original rental-count units. Standard deviations describe seed variability. The seed-17 bootstrap resamples weeks for Bike Sharing and descriptor groups for Letter Recognition within that split.

The controlled task has 8,192 samples per scenario and uses known equations with constant or input-dependent signed gains. The targets come from independent staged iteration. This experiment isolates the gain recovery mechanism. Its teacher is generated by construction and the larger-task results provide the separate predictive comparison.

| Refit comparison | Fixed anchor | Calibrated signed gate |
|---|---:|---:|
| Bike Sharing chronological holdout RMSE | 80.61 | 78.95 |
| Letter Recognition accuracy | 95.77% | 95.77% |
| Smallest held-out certification rate at 1e-5 | 100% | 100% |

On Bike Sharing, the calibrated gate lowered mean RMSE by 2.06% relative to the fixed-gain anchor. Mean warm CPU time was 0.070 ms per row with the calibrated gate and 0.062 ms per row with fixed gains. The standard cubic KAN reached 77.35 RMSE on Bike Sharing and 95.91% accuracy on Letter Recognition. The signed gate improved on its exact anchor in two Bike Sharing seeds, increased RMSE in one seed, and reproduced the anchor in the two seeds with zero selected strength.

On the sign-switching controlled task, the calibrated gate reached mean RMSE 0.0392 and contextual reciprocal gains reached 0.8693. The fixed-gain controlled task selected strength zero in all three calibrated signed runs.

## Reproduce

Use Python 3.11 or newer with the dependencies in `requirements.txt`. After dependency installation, data, fitting, inference, and rendering run offline.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python fit_baselines.py --workers 7
python gate_study.py fit --workers 7
python controlled_task.py --workers 6
python gate_study.py evaluate
python paper_tables.py
python paper_figures.py
python replay.py bike --seed 17 --limit 5 --output replay.csv
```

For repeatable latency measurements, run `gate_study.py evaluate` after the training processes finish. The measurement includes the trunk, active gate, direct equilibrium solve, state bound, and output interval. It excludes dataset loading and model loading. Each seed uses three warm repeats on up to 1,024 deterministically spaced rows at batch size up to 128 and one BLAS thread.
